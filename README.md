# 💼 Gestor de Ofertas Laborales IT (.NET 8 / C#)

Aplicación de consola interactiva desarrollada en **C#** sobre **.NET 8**, diseñada para la gestión, registro y filtrado de ofertas de empleo para perfiles tecnológicos.

## 🚀 Características
* **Modelo de Datos POO:** Encapsulamiento de propiedades de vacantes en clases especializadas.
* **Consultas Eficientes con LINQ:** Filtrado dinámico de ofertas por tecnología (C#, React, etc.) y modalidad de trabajo (Remoto/Presencial).
* **Gestión de Errores:** Validación de entradas de usuario mediante bloques `try-catch` para evitar fallos de formato en ejecución.
* **Estructura Escalable:** Preparado para conectar con bases de datos relacionales o APIs RESTful.

## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** C# 12
* **Framework:** .NET 8.0 SDK
* **IDE:** Visual Studio 2022
* **Conceptos clave:** POO, LINQ, Lambda Expressions, Exception Handling.
